Projet Dev Web L2 - Site E-commerce Mely Beauty

--- LIEN DE DÉPLOIEMENT ---
https://melybeauty.netlify.app/

--- DESCRIPTION ---
Ceci est notre projet pour le module de dev web. C'est un site pour vendre du maquillage (marque sheglam).
On a utilisé que du HTML, CSS et JS comme demandé, sans framework ni php derrière.
Le site marche avec le localStorage pour simuler la base de données (pour le panier et les inscriptions).

--- UTILISATION ---
1. Ouvrez index.html avec chrome ou firefox.
2. Vous pouvez voir les produits et les filtrer par catégorie avec la barre en haut de la page produits.
3. On peut ajouter au panier. Le panier se mets à jour avec le javascript et stocke dans le memory du navigateur.
4. Pour tester la connexion, on a mis des comptes de base (voir index javascript pour les mots de passe) ou créez-en un nouveau. La validation avec regex marche.
5. La page de commande marche aussi pour voir le total. Livraison gratuite à 3000 dz.
